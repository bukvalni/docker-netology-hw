# Домашнее задание к занятию «Микросервисы: подходы»

### Задание 1

Выбор: GitLab + HashiCorp Vault

Хранение кода: Для каждого микросервиса создаётся свой отдельный репозиторий внутри одной группы в облачном GitLab

Запуск сборок: Сборка запускается автоматически либо вручную через кнопку в интерфейсе, где можно выбрать нужные параметры (среду, параметры тестов)

Гибкость и шаблоны: Настройки сборок описываются в файлах конфигурации. Их можно шаблонизировать и использовать повторно для разных сервисов. Из одного репозитория можно собирать разные варианты приложения

Безопасность: Пароли и ключи хранятся в защищённом хранилище Vault и подтягиваются прямо во время сборки

Собственные серверы: На ваши серверы ставятся программы-агенты (GitLab Runner). Они запускают сборку в ваших собственных Docker-образах с любыми кастомными командами, умеют выполнять задачи и тесты параллельно


### Задание 2

Выбор: Grafana Loki + Vector + Grafana

Сбор логов: На каждый сервер ставится лёгкая программа Vector. Приложениям не нужны сложные библиотеки — они просто выводят текст в консоль (stdout), а Vector подхватывает эти записи

Надёжность: Если сеть «упадёт», Vector сохранит логи на диск сервера и доставит их в хранилище сразу после восстановления связи

Хранилище: Логи стекаются в Grafana Loki. Система быстро работает и занимает мало места на диске

Интерфейс и ссылки: Разработчики заходят в удобный веб-интерфейс Grafana, ищут логи по фильтрам и могут скопировать готовую ссылку на результат поиска, чтобы отправить её коллеге

### Задание 3

Выбор: Prometheus + Grafana

Метрики серверов: На серверы ставится модуль Node Exporter, который собирает данные о нагрузке процессора (CPU), оперативной памяти (RAM), дисках (HDD) и сети

Метрики контейнеров: Модуль cAdvisor отслеживает, сколько ресурсов потребляет каждый отдельный микросервис

Специфичные метрики: В код микросервиса добавляется специальный адрес (например, /metrics), откуда Prometheus забирает данные о работе приложения (количество запросов, ошибки, скорость ответа)

Интерфейс и графики: В Grafana создаются дашборды с графиками. Там можно писать запросы, объединять данные и наглядно видеть состояние всей системы
