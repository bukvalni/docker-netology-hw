Выбор решения: Kong API Gateway

Обоснование выбора:

Соответствие требованиям:

Маршрутизация: Отлично справляется с динамической маршрутизацией запросов по путям, заголовкам, методам и хостам. Поддерживает работу в режиме Kubernetes Ingress Controller

Аутентификация: Обладает экосистемой плагинов для валидации JWT, OAuth2 и интеграции с Keycloak/Dex «из коробки», без необходимости писать кастомный код

Терминация HTTPS: Осуществляет терминацию TLS с поддержкой автоматической ротации сертификатов и централизованного управления

Масштабируемость и архитектура: Построен на базе высокопроизводительного ядра OpenResty/NGINX. Поддерживает архитектурный шаблон Data Plane / Control Plane (DB-less режим), что позволяет безопасно и быстро масштабировать Gateway в Kubernetes

### Задание 2

 Критерий | Apache Kafka | RabbitMQ | Apache Pulsar | Redis Streams |
|----------|--------------|----------|---------------|---------------|

Выбор решения: RabbitMQ (с Quorum Queues) или Apache Kafka

Для большинства микросервисных архитектур выбор зависит от основного паттерна использования:

Основное предложение — RabbitMQ (Quorum Queues):

Идеально подходит для классического межсервисного взаимодействия (RPC, Task Queues, Pub/Sub, сложные маршрутизации AMQP)

Соответствие требованиями:

Кластеризация и надежность: Использование Quorum Queues на базе консенсуса Raft гарантирует защиту от потери данных и корректный failover

Хранение на диске: Все важные сообщения транзакционно сбрасываются на диск.

Разделение прав: Поддержка Virtual Hosts (vhosts) и гибкой ролевой модели ACL позволяет изолировать команды и сервисы

Простота: Поставляется с готовым веб-интерфейсом управления, легко мониторится и администрируется

Альтернатива (если приоритет Event Streaming и Event Sourcing) — Apache Kafka:

Если система строится вокруг аналитики в реальном времени, постоянного хранения истории событий и требует пропускной способности в сотни тысяч запросов в секунду, целесообразно выбрать Apache Kafka. С отказом от ZooKeeper (режим KRaft) эксплуатация Kafka стала существенно проще
